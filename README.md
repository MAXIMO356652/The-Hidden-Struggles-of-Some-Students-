# THE WAITING-MAXIMO — Student Chapter

A standalone, responsive reading page for **Same Age, Different Lifestyle — Same Experience, Different Time**.

## Publish on GitHub Pages

1. Create a new GitHub repository, for example: `same-age-different-lifestyle`.
2. Upload `index.html` to the root of the repository.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/(root)`, then save.
6. Wait for GitHub Pages to publish the site. Your page URL will appear in the Pages settings.

If you already have a GitHub Pages repository and want this chapter on that site, upload the file under a new folder, for example `same-age-different-lifestyle/index.html`. The page will then normally be available at:
`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/same-age-different-lifestyle/`

Replace the uppercase placeholders with your actual GitHub username and repository name. Do not overwrite an existing `index.html` unless you intend to replace the current homepage.
